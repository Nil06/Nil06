### What I am building

I am interested in software that gives people more leverage without locking them into expensive infrastructure or opaque platforms.

- **Local-first AI tools** that run close to the user and keep data private.
- **Browser extensions and web utilities** that remove daily friction.
- **Open-source products** with simple setup, clear UX, and sustainable costs.
- **Developer-facing tools** where speed, reliability, and product taste matter.
